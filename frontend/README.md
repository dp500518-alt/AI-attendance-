# AI Smart Attendance - Frontend (React + Vite)

The decoupled Single Page Application (SPA) frontend for the AI Smart Attendance System built using **React 18**, **Vite**, and **React Router v6**.

## Features
- **Role-Based Portals**: Admin Executive Dashboard, Teacher Portal, Student Portal
- **Real-Time Webcam & Photo Upload**: Interactive classroom face recognition
- **Student & Faculty Management**: Registration, search, directories, embeddings status
- **Timetable & OCR Parser**: Schedule grid and automated image OCR import
- **Analytics & Diagnostic System**: Visual metrics and storage diagnostics

## Development Setup

```bash
# Install dependencies
npm install

# Start local Vite development server (port 5173)
npm run dev

# Build production bundle
npm run build
```
